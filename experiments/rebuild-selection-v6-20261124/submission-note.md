# RAC-HPO 提交说明（v6，2026-11-24）

## 本次变更

v5 已把「解析回退」与「决策塌缩」修好（30/30 合法、动作 A 10/10 RAC、B 5:5、C 6:4），
但 C 的隐藏指标仍停在 41.176。用平台真实 C 数据包（FD001 公开训练 113,089 行 /
验证 23,049 行 + 官方 833 参数检查点）复现其 10 轮轨迹后定位到两个训练侧问题，本次修这两个：

1. **续训改为轮末权重平均**（`rac_hpo.contest.continuation.fit_epochs`）。
   父检查点已在最优点附近，固定学习率下逐 epoch 权重来回振荡，接受门几乎每轮都拒绝候选，
   轮次被白白消耗。改为对 epoch 末权重做 EMA（decay 0.6）后，优化步数不变、振荡消失。
   仅作用于回归任务（B/C），分类（A）保持原路径不变。

2. **回归任务学习率下限 3e-3**（`ContestRACPolicy.space`）。
   v5 的 C 在 r2 起被搜索策略压到 `lr=1.1e-5`，1–5 个 epoch 内参数几乎不动，10 轮只有 3 轮真正
   改善。公开包上实测：`lr=1.1e-5` → MAE 37.91；`lr∈[3e-3,1e-2]` → MAE 36.74–36.78。
   父检查点自带学习率（0.002）低于新下限，`checkpoint_reference` 分支改为夹取到空间内，
   避免第一轮直接报错。

## 本地验证（平台真实数据，非合成）

- 复现保真度：用 v5 的真实逐轮参数在本地重放，末轮 MAE 37.90685，平台报告 37.90518，差 0.0016。
- 10 轮续训（同父检查点、同接受门）：父 38.8998 → **36.7811**（MAE −5.4%），
  RMSE 52.8686 → 51.1374（−3.3%），接受轮次 1/10 → 9/10。
- 按物理单元对半切开交叉验证：两半均改善（41.76→38.20、35.98→35.33），非单侧调参。
- 对照：不加平均、`lr=1e-3` → 38.02（接受 1/10）；加噪声增强 → 0/10 全被拒，已弃用。
- 时窗统计特征（wmean/wstd/wslope）离线上限为 36.60，但**不可上线**：预测请求只带
  `{task, inputs}`，无 unit/cycle、无历史，父检查点也已固定 24→32→1 结构。
- 测试：竞赛 68 项（67 通过、1 跳过）、SDK 回调 21 项，全通过。
