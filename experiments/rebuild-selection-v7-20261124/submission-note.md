# RAC-HPO 提交说明（v7，2026-11-24）

## 本次变更

v6 把 C 的公开验证从 MAE 38.90 压到 36.78，但平台隐藏实测 C 反而退步 0.36%（B 大幅 −25.7%）。
本次针对 C 任务做时序方向（路线 A）的最终落地——把时序信息以「软标签蒸馏」的方式注入训练目标，
不改预测输入、不改检查点架构、不改 mean/scale/paths，平台侧零感知。

1. **OOF 时序软标签蒸馏**（`contest_submission.apply_soft_labels`）。
   - 教师：离线用 `public/train.jsonl` 的 `meta.unit/cycle` 重建 87 维因果滑窗，按 unit 分 5 折做
     OOF 预测（教师从不看自己要预测的单元），hidden 64 / 40 epoch，OOF MAE 37.4。
   - 学生目标：`y_soft = y_true + 0.3 * (teacher_oof - y_true)`，学生仍是 24→32→1、833 参数，
     从父检查点续训。软标签随镜像打包（`/app/soft_labels_C.npz`），按样本 id 对齐注入，只改训练目标。
   - 仅作用于 C 回归任务；A（分类）、B（回归）完全不受影响。
   - 评估仍用真实验证标签，候选预处理校验（mean/scale/paths/target_mean/target_scale）不变。

2. **EMA decay 0.6 → 0.4**（`rac_hpo.contest.continuation.EMA_DECAY`）。
   288 组网格搜索显示，叠加软标签后最优衰减为 0.4（配合 lr=4e-3、epochs=5）。

## 本地验证（平台真实数据，非合成）

- 288 组网格（窗口×软标签×β×decay×lr×epochs）+ 30 轮 + 双 fold-seed + split-half：
  最优 `w30 + β0.3 + decay0.4 + lr4e-3 + ep5`，RMSE 52.87 → **51.14**（−3.3%）。
- 分解：纯训练侧 decay0.4 是 51.27，加蒸馏到 51.14，**时序净贡献 ≈ 0.10 RMSE（−0.2%）**。
- 两半集（按物理单元对半切）均改善，双 seed 结论一致，无泄漏。
- 三条技术路线证伪后保留唯一有效者：软标签蒸馏 ✅；时序样本加权 ❌（51.71 差于基线）；
  权重迁移 ❌（归一化空间不同，迁移即崩）。
- 测试：竞赛 68 项（67 通过、1 跳过）全绿。
