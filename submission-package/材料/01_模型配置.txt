一、平台锁定模型架构（不可更改，本方案零侵入）
--------------------------------------------------------------------------------
任务 A  气体识别（分类）
  模型类型        : 多层感知机（MLP）
  输入维度        : 24
  隐藏层          : 24 -> 32
  输出            : 类别数（多分类，含 softmax）
  可训练参数      : 4,326
  主指标          : Macro-F1（越高越好）
  验证单元        : class（类别）

任务 B  轴承剩余寿命预测（回归）
  模型类型        : 多层感知机（MLP）
  输入维度        : 24
  隐藏层          : 34 -> 24 -> 1
  输出            : 1（RUL 分钟）
  可训练参数      : 865
  主指标          : RMSE（越低越好），辅助 MAE
  验证单元        : bearing（轴承）

任务 C  涡扇发动机剩余寿命预测（回归）
  模型类型        : 多层感知机（MLP）
  输入维度        : 24
  隐藏层          : 24 -> 32 -> 1
  输出            : 1（RUL 循环）
  可训练参数      : 833
  主指标          : RMSE（越低越好），辅助 MAE / NASA 评分
  验证单元        : unit（运行单元）

  公共约束：
    输入 schema  : {"task": <str>, "inputs": <array[N,24]>}，不含 unit/cycle/历史
    不保证行顺序  : 预测请求按行独立处理，模型不得依赖样本间顺序
    依赖限制      : requirements-contest.txt 固定，不含 torch；仅 numpy/scikit-learn
    检查点格式    : checkpoint.npz（含 params / mean / scale / paths / meta）

二、决策采样器（PyTRIO 平台训练所得）
--------------------------------------------------------------------------------
  采样器指针      : trio://run_1fei9lfkoj70/sampler_weights/
                    industrial-harness-lora-selection-v3-20261124
  基座模型        : Qwen/Qwen3.5-4B（允许列表内）
  训练方式        : LoRA 微调（选择合同）
  训练记录        : https://swanlab.cn/@2025040064/industrial-harness-sft/runs/ax998s81
  训练样本        : 36 条（反事实配对，18 RAC : 18 conservative 平衡）
  训练轮次/步数   : 4 epochs / 72 steps
  学习率          : 2e-4
  留出样本        : 10 条
  两类可达性守卫  : 通过（留出 2 RAC / 8 conservative；改善历史 4/4 RAC；被拒历史 0/4 RAC）

  决策输出合同（decision_contract.md 为唯一约定）：
    允许形式 A：原文归一化后精确等于 RAC 或 conservative（大小写不敏感，
                仅剥离恰好一个末尾 <|im_end|>）
    允许形式 B：单个 JSON 对象，字段恰好为
                {"selected_option": "RAC"|"conservative",
                 "reason_codes": [history|risk|constraint|cost|uncertainty|conservative|other],
                 "risk": "low"|"medium"|"high"|"unknown"}
    其他任何形式回退 conservative_invalid_response，并记录原因码

三、超参数搜索空间（RAC-HPO 每轮在空间内提出候选）
--------------------------------------------------------------------------------
  learning_rate   : float, log 尺度
                    任务 A        : [1e-5, 1e-2]
                    任务 B / C    : [3e-3, 1e-2]   ← v6 起启用学习率下限 3e-3
  batch_size      : int, log 尺度, [16, 512]
  epochs          : int, [1, 5]
  sampling_level  : int, [1, 16]（任务 A） / [1, 2]（任务 B、C）
  strategy        : uniform（默认） / unit_balanced（按验证单元均衡重采样）

四、RAC-HPO 寻优配置
--------------------------------------------------------------------------------
  基础算法        : TPE（Optuna TPESampler，n_startup_trials = 4）
  暖启动门槛      : warmup_trials = 8, minimum_history = 8
  前向验证门槛    : min_forward_train = 5, forward_holdout = 3
  代理重训间隔    : refit_interval = 1
  代理模式        : shadow（默认；仅预测不参与排序，通过质量门禁后可切 active）
  代理模型        : ExtraTrees 集成（性能代理 + 成本代理）
  代理质量门禁    : 前向 holdout 的 Spearman 秩相关 / MAE 比值门槛
  成本指数        : gamma = 0.5（cost_mode ∈ {acquisition, both}），否则 0.0
  成本对数门限    : maximum_cost_log_mae_ratio = 1.0

五、鲁棒目标（选模依据）
--------------------------------------------------------------------------------
  归一化工况误差  : r_g = E_g / (B_g + epsilon)
  基础目标        : J = 0.7 × Σ(p_g × r_g) + 0.3 × max(r_g)
                    其中 p_g 为工况验证样本占比，B_g 为工况基线误差
  后期目标        : J = N × E_avg + (1 - N) × E_worst
  alpha           : 0.3
  epsilon         : 1e-9

六、训练侧配置（v8-B 关键改动）
--------------------------------------------------------------------------------
  EMA 权重平均    : 仅任务 C 启用（decay = 0.6）
                    任务 B 已关闭（v8-B 改动，S2 消融 G2 策略）
                    任务 A（分类）不做权重平均
  学习率下限      : 回归任务 3e-3（父检查点 lr 低于下限时夹取，避免首轮报错）
  每轮续训轮次    : 1 ~ 5 epochs（由搜索器提出，单轮上限 5）
  CPU 线程        : 1（平台配额）

七、准入与验收规则
--------------------------------------------------------------------------------
  主指标改善      : 平台主指标（A=macro_f1 升，B/C=RMSE 降）须优于父模型
  鲁棒目标改善    : robust_objective 须同比下降
  多工况门禁      : 总体 ≤ 1.02×，单工况（轴承/单元）≤ 1.05×
  未达标处理      : 一律拒绝并保留原父模型（不劣化保证）
  检查点保护      : 保留历史最优检查点，支持一键回滚
