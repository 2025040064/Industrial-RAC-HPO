# S2 正式消融：CPU 预算协议（预注册）

日期：2026-11-25
依据：v6 平台 B 任务 CPU 成本 695.89 秒（10 轮单线程，来自平台 report）

## 本地硬件基准（预注册，实测）

| 项 | 本地实测 |
|---|---|
| 单轮续训 epochs=2 CPU | ~0.01 s |
| 单轮验证（diagnostics+primary）CPU | ~0.001 s |
| 单轮 propose（无历史）CPU | ~0.000 s |
| PyTRIO 决策网络延迟（单次） | ~0.5-2 s（wall-clock，非 CPU） |

## 关键结论：本地 vs 平台 CPU 计量口径不同

平台 695.89s/10轮 ≈ 70s/轮，本地训练+验证 CPU ≈ 0.01s/轮，相差 ~7000 倍。
平台 CPU 计量包含容器调度、SDK RPC、隐藏集评测等，本地无法复现该口径。
因此：**本地实验以「等轮数」为第一对照口径**（本地 CPU 极便宜，等轮数≈等预算），
并同时记录本机 CPU 分项，供后续对照。不将本地 CPU 时间与平台 695.89s 直接等价。

## 预注册硬预算

- 正式消融：4 组 × 3 种子 × 10 轮 = 120 轮，每组独立父链与搜索历史。
- 每轮预算上限：训练 CPU 无硬上限（本地极快），PyTRIO 网络单次调用超时上限 60s、重试 3 次。
- 预算耗尽判定：以「PyTRIO 调用全部失败且重试耗尽」为软停条件；否则跑满 120 轮。
- 预算耗尽时保留最后一个合法接纳的 Checkpoint（best 模型），并记录其 SHA 与 RMSE。

## 种子语义（明确）

- `seed` 控制的是 **搜索随机性**（ContestRACPolicy/RACSearchPolicy/TPE 的采样种子）。
- **训练种子保持父检查点原值 42**（model.meta["seed"] 不变），四组一致。
- 因此本实验是「多搜索种子实验」，不是「多训练种子实验」。

## 收益口径（严格区分）

- 公开验证集收益：本实验唯一可本地测得的指标。
- 跨设备泛化收益：逐轴承 RMSE（独立研究口径，非平台口径）。
- 隐藏集收益：本地不可测，仅平台最终评测一次，本实验不得拟合。
